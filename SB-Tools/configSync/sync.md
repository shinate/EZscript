# sync.bat 使用说明

## 配置文件书写规范

配置文件使用 INI 格式，文件扩展名建议为 `.ini`。同步参数写在 `[Sync]` 区段中：

```ini
[Sync]
SOURCE=C:\Users\YourName\Documents\source.docx
DEST=D:\Backup\source.docx
DEST=\\NAS\Shared\source.docx
```

书写规则：

- 必须有 `[Sync]` 区段；区段名和键名不区分大小写。
- `SOURCE` 指定源文件路径，至少填写一个非空值。可以重复填写；**最后一个 `SOURCE` 值生效**。
- `DEST` 指定目标文件路径，至少填写一个非空值。可以重复填写，每一项都会作为一个同步目标。
- 键名和值之间使用 `=`，不要给键名、区段名或等号两侧添加空格。
- 路径值不要加引号；路径中包含空格时也不需要引号。
- 可用以 `;` 或 `#` 开头的整行注释；注释符必须位于行首，不支持行尾注释。
- `[Sync]` 以外区段中的内容不会被读取。

配置文件路径、源文件路径和目标文件路径中包含空格时，请按原样填写路径；**命令行参数**中的路径则需要加引号。

## 执行命令

在 `sync.bat` 所在目录打开命令提示符：

```bat
sync.bat "sync_config.example.ini"
```

也可以从任意目录使用脚本和配置文件的完整路径：

```bat
"D:\path\to\SB-Tools\sync.bat" "D:\path\to\sync_config.ini"
```

必须传入配置文件路径。相对配置文件路径以当前命令提示符所在目录为基准，而不是以 `sync.bat` 所在目录为基准。同步完成后，脚本会等待按键退出。

## 同步行为

- 源文件不存在或未配置源文件、目标时，脚本会报错并退出。
- 目标目录不存在时，该目标会被跳过；目标目录需要预先创建。
- 复制时使用覆盖模式，已有的目标文件会被覆盖。

可参考同目录下的 [sync_config.example.ini](./sync_config.example.ini)；使用前请将示例路径替换为实际路径。
